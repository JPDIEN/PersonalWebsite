# DealDesk

**A local-first deal-flow pipeline for early-stage investing: ingest company CSVs from
anywhere, score them against your thesis, and run your week from one dashboard.**

No accounts, no API keys, no dependencies beyond Python 3.10+. Everything lives in one
SQLite file you own.
